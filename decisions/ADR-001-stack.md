# ADR-001: Technology Stack

## Status

Accepted

## Decision

CodeLens AI will initially use:

### Frontend

React + TypeScript + Vite + Tailwind CSS

### Backend

Node.js + TypeScript + Express

### Database

PostgreSQL

### Repository

GitHub

### Development

VS Code

## Reasoning

This stack provides:

* Strong TypeScript support
* Familiar full-stack development workflow
* Good ecosystem support
* Clear separation between frontend and backend
* Strong portfolio relevance for software engineering roles

The architecture should remain simple during the MVP phase.

Additional infrastructure should only be introduced when required by an actual feature.
